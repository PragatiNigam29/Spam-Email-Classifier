# Spam Email Classifier

## Project Overview

This project is a Machine Learning-based Spam Email Classifier that detects whether a message/email is **Spam** or **Not Spam**. The model is trained using a dataset of SMS/email messages and predicts the category of new messages.

## Features

* Detects Spam and Non-Spam messages
* Uses Machine Learning for prediction
* Text preprocessing using CountVectorizer
* Simple and beginner-friendly implementation

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn

## Machine Learning Algorithm

* Multinomial Naive Bayes

## Dataset

The dataset used contains labeled messages categorized as:

* **Spam**
* **Ham (Not Spam)**

## Project Workflow

1. Import libraries
2. Load dataset
3. Data preprocessing
4. Convert text into numerical format
5. Split training and testing data
6. Train the model
7. Check accuracy
8. Predict new messages

## Example Prediction

**Input:**
`Congratulations! You won a free iPhone. Click now!`

**Output:**
`Spam Email`
